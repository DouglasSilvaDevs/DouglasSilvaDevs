## 🚀 Projeto em destaque

### FinanSee

Aplicativo de gerenciamento financeiro pessoal desenvolvido com **Flutter**.

Principais funcionalidades:

- Controle de receitas e despesas
- Gerenciamento de contas
- Orçamentos mensais
- Metas financeiras
- Transações recorrentes
- Relatórios e gráficos
- Notificações
- Backup e restauração
- Exportação em PDF e CSV
- Tema claro e escuro

🔗 [Ver projeto no GitHub](https://github.com/DouglasSilvaDevs/finansee)
